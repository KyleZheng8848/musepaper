# SofunAI Studio / SofunAI 工作室

Musepaper is published and maintained by **SofunAI Studio**.

Musepaper 由 **SofunAI 工作室**出品并维护。

## Logo assets / 标识素材

- `sofunai-mark.svg`: square studio symbol / 工作室方形标识。
- `sofunai-logo-light.svg`: wordmark for light backgrounds / 浅色背景横版标识。
- `sofunai-logo-dark.svg`: wordmark for dark backgrounds / 深色背景横版标识。
- `tokens.json`: reusable studio palette / 可复用的工作室配色。

The README uses a `<picture>` element to select the wordmark for the reader's color scheme. All assets are self-contained SVGs with transparent backgrounds; they require no external images, fonts, or scripts. The wordmark uses system font fallbacks.

README 使用 `<picture>` 随阅读环境切换标识。素材为透明背景 SVG，不加载外部图片、字体或脚本；字标使用系统字体回退。

## Studio identity / 工作室视觉

The studio identity brings together approachable desktop companions, editorial workflows, and clear creative technology. Warm paper (`#F6EFE0`), coral (`#E07A5F`), mint (`#2A7A6A`), and a small sky-blue accent (`#7EB8DA`) pair with rounded typography. Two soft interlocking loops suggest exchange and collaboration; their combined gesture recalls an S.

工作室视觉结合桌面伙伴的亲和感、编辑工作流的清晰秩序与创作工具的通透感。暖纸白、珊瑚橘、薄荷青和少量冰蓝配合圆润字形；两段柔和交扣的曲线表达交流与协作，组合成 S 的姿态。

Use the same studio logo as the publisher endorsement across products. Each product keeps its own name, app icon, and visual accents. The core logo stays legible as a flat vector; translucent or optical materials can appear in surrounding presentation graphics.

各产品使用同一工作室标识作为出品署名，并保留各自的名称、应用图标与强调色。核心 logo 保持平面矢量的清晰度；通透、光学材质可用于展示环境与辅助图形。

The studio logo and its preview contain only the SofunAI Studio identity. Project names belong in each project's title and About information, outside the logo. Each open-source project should show the publisher in its README and, when it has an application interface, its About screen.

工作室 logo 及其预览仅展示 SofunAI 标识。项目名称放在各自标题与关于信息中，独立于 logo。每个开源项目的 README 都要标注工作室；有应用界面的项目还应在关于页显示 logo、工作室署名与项目链接。
