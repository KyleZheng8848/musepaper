# SofunAI Studio / SofunAI 工作室

Musepaper is published and maintained by **SofunAI Studio**.

Musepaper 由 **SofunAI 工作室**出品并维护。

## Logo assets / 标识素材

- `sofunai-mark.svg`: square studio symbol / 工作室方形标识。
- `sofunai-logo-light.svg`: wordmark for light backgrounds / 浅色背景横版标识。
- `sofunai-logo-dark.svg`: wordmark for dark backgrounds / 深色背景横版标识。

The README uses a `<picture>` element to select the wordmark for the reader's color scheme. All assets are self-contained SVGs with transparent backgrounds; they require no external images, fonts, or scripts. The wordmark uses system font fallbacks.

README 使用 `<picture>` 随阅读环境切换标识。素材为透明背景 SVG，不加载外部图片、字体或脚本；字标使用系统字体回退。

The visual palette combines midnight blue (`#142235`), amber (`#F3B562`), and mint (`#8AD5C1`). The flowing S references a folded ribbon and the studio name.

配色由深蓝、琥珀色与薄荷色组成，流动的 S 呼应折叠纸带和工作室名称。
